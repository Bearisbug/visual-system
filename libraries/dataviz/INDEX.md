# 图表系列色预置色板

图表系列色 `semantic.color.dataViz.series.1…6` 从这里的四套色板选一套，不从品牌色派生。规则在 [BD-TOKEN-001](../../references/system.md#bd-token-001) 第 8 步，机读数据在 [presets.json](presets.json)。每套有 6 个系列色和 2 个备用色，每色都有浅色、暗色两个色值。

![四套预置色板在中性灰浅色、暗色表面上的堆叠柱、折线与环形图](preview.png)

## 选哪一套

默认选「鲜明」：图表要一眼分清各系列，6 色彩度 0.11–0.24。下面的条件命中时换：

| 色板 | 换用条件 | 代价 |
| --- | --- | --- |
| 标准 `standard` | 用户或品牌手册要求图表不压过品牌色，且强调色 OKLCH 彩度 < 0.15 | 彩度 0.11–0.15，暗色亮度 0.70–0.84，醒目程度低于鲜明 |
| 柔和 `soft` | `primitive.color.brand.*` 的彩度都 < 0.10，且图表不是产品的主要内容 | 彩度 0.10–0.12，四套里最安静 |
| 粉彩 `pastel` | 品牌参考或用户偏好里有粉彩、马卡龙一类浅色调，且暗色是默认模式或主要使用模式 | 浅色模式不是粉彩，见下文 |

选定的色板写进 dataViz 组的 `$description` 和 DESIGN.md。

粉彩的暗色取自 Coolors 色板 FFADAD、FFD6A5、FDFFB6、CAFFBF、9BF6FF、A0C4FF、BDB2FF、FFC6FF（[coolors.co/palette](https://coolors.co/palette/ffadad-ffd6a5-fdffb6-caffbf-9bf6ff-a0c4ff-bdb2ff-ffc6ff-fffffc)），彩度提到 ≥ 0.105、亮度不高于 0.91，以过彩度下限和暗色亮度带；第 9 色 FFFFFC 接近白色，不用。原色放在浅色表面上过不了 3:1（FDFFB6 对白色约 1.04:1），所以浅色模式用同一组色相、加深到 L 0.55–0.60 的版本。

## 已经满足和要按品牌核对的门

色值在 OKLCH 里定，换算成 8 位 sRGB。每套按上表顺序，在浅色、暗色两套里都过了 [tokens-schema](../../vendor/theme-extract/references/tokens-schema.md) §6.3 里与表面无关的门：亮度带（浅 0.43–0.77、暗 0.60–0.92）、彩度 ≥ 0.10、相邻两号与系列 1–3 两两的色盲模拟 ΔE ≥ 8 和正常视觉 ΔE ≥ 15，以及本技能另加的全部两两正常视觉 ΔE ≥ 8。

| 色板 | 相邻最差色盲 ΔE（浅 / 暗） | 全部两两最差正常视觉 ΔE（浅 / 暗） |
| --- | --- | --- |
| 鲜明 | 12.7 / 14.2 | 11.1 / 11.2 |
| 标准 | 12.8 / 12.9 | 9.2 / 10.0 |
| 柔和 | 11.5 / 11.6 | 9.4 / 10.0 |
| 粉彩 | 14.8 / 12.2 | 8.5 / 8.0 |

对四层表面 3:1 和离反馈色的距离取决于品牌的表面色和反馈色，由 `node <skill>/scripts/dataviz-preset.mjs <tokens 目录> --preset <id>` 按本品牌核对：某号在任一模式没过亮度带、彩度下限或 3:1 时，换成第一个能过且换后整组仍过区分度的备用色；两个备用色都不行时脚本退出码为 1，这时换一套色板，或在 DESIGN.md 记下缺口并问用户。离反馈色 ΔE < 15 只报警告。

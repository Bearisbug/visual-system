# 像素网格与离散图形

品牌希望用有限方块、阶梯轮廓或网格选择动作表达数字原生、识别、编码与组合时，使用本包。触发语包括“像素品牌”“Mistral 那种方块图形”“用网格做 AI 品牌”；不能仅因产品属于科技行业就选此方法。用户任务、已有品牌资产与上层规则优先，参考页面中的品牌使用说明只约束其原品牌资产。

本包的“像素”指有意设计的离散视觉单位，来源图仍可保持清楚；不是降低文件分辨率。样本以直角方块和阶梯为主，**尚未覆盖圆点阵、点阵字体或复古游戏场景**。需要一般模块容器及自由形状组合时，读取[可组合与可变识别](../modular-responsive-identities/STYLE.md)；需要精确字母融合时，也可对照[科技语义与字母融合](../semantic-tech-marks/STYLE.md)。

本包的[当前示例](EXAMPLES.md)共有 10 张图：2 张 AI 重新演绎与 8 张文字简报原创研究，按[艺术方向](../ART-DIRECTION.md)展示。前者的实际 Prompt、源样本与目检见[重新演绎记录](generated.json)；后者的简报、构思、实际 Prompt 与目检见[原创研究记录](originals.json)。原创研究的 `input_files` 为空，不对应源案例；虚构主体与生成细节不归属于 `source_collection` 中的作者或品牌。原作观察与事实以[来源档案](REFERENCES.md)为依据，AI 图像不能反写为原作参数。

本包的来源档案有 **2 个独立品牌项目、10 份原采集素材、3 份确定性格式预览**。按需读[逐例 AI 示例](EXAMPLES.md)、[Prompt 模板](PROMPTS.md)和[来源清单](sources.json)。Mistral 的角色题材仅是其案例事实，不将猫或其他动物设为新科技品牌的默认构思。

## 两条构思路线

| 分支 | 参考与可见关系 | 迁移决策 |
| --- | --- | --- |
| 紧凑符号与像素图标家族 | PG01：固定符号配平滑字标；模型图标改变主体与颜色，仍沿离散边缘绘制 | 先定义自有品牌的核心含义，再分别设计标准标志与系列图标。系列关联来自单位、角度、密度等共同约束，不要求重复同一吉祥物 |
| 产品动作转成网格语言 | PG02：字母符号、照片的阶梯窗口、选择角标、错位条带形成不同用途 | 从产品的选择、定位、分组或匹配动作提取关系；固定标志、图片遮罩与背景图形分别维护，不把任意方块排列都称为品牌变体 |

以上是对所收图片的观察与本库推导；原作构思的来源说明见 REFERENCES。两条路线可以组合，但须交代各层职责，不能叠加整套现成身份。

## 可调参数与保持项

参数用于本次设计决策，不是从原作测出的规范数值，也不是新增 token 字段。

| 参数 | 允许探索 | 保持与检查 |
| --- | --- | --- |
| 基本单位 | 方块边长、网格稀密、横竖排列 | 同一资产内采用已声明的单位关系；需要光学校正时记录独立用途，不静默扭曲单个格子 |
| 正负形 | 实心块、阶梯开口、空格数量 | 核心字母或语义在目标小尺寸仍成立；不要靠文案解释被堵住的开口 |
| 变化范围 | 图标主体、辅助条带长度、照片窗口、图形占比 | 标准 Logo 不随内容任意重排；辅助系统可变范围单独列出 |
| 色彩 | 单色验证后选择有限色阶或多色角色 | 阶梯色带与平滑渐变是不同选择；产品区分不能只靠颜色 |
| 字体 | 平滑字标/正文与像素图形形成分工；显示文字是否离散化另定 | 不默认整套正文像素化；中文、数字、标点、小字号须用真实文件试排 |
| 背景网格 | 显示、弱化或隐藏网格，改变密度 | 参考构造网格不等于用户界面必须铺满格线；文字、表单、图表先保持清楚 |
| 输出尺度 | 矢量网格母版、目标尺寸栅格导出 | 整数步进、像素对齐与抗锯齿按目标介质验证；锐利不能靠破坏轮廓或给低清图插值放大获得 |

## 字体角色

两项目都有平滑字形与离散图形并存的可见证据，不能据此认定所有像素品牌必须搭配等宽字体。标志中的文字、宣传标题、正文/UI、数字/代码分别设定角色；同一家族可以兼任。

本包未核实两项目使用的准确字体家族、文件版本或许可，不能照外观报字体名。需要中文时选可取得且授权匹配的字体，用真实品牌名和长短文案试排；正式文字保持可编辑。像素字若是用户明确的方向，另做逐字可读性与中文覆盖研究，不将本包当作已有字体资源。

## 从品牌到应用

1. **构思**：用一句话写出产品动作与要表达的关系，先确定像素单位为何必要。若理由只有“科技感”，继续构思，不急于加网格。
2. **识别**：先做单色轮廓或网格草案，区分自有主标志、系列图标、装饰图形。比较时使用同色同尺度，避免仅换色冒充新构思。
3. **系统**：写明固定项、可变项与边界。给不同图标同一画幅及视觉重量，保留轮廓区分，避免把官方模型名称搬进新项目。
4. **应用**：在用户需要的真实文案、横竖比例和小尺寸中验证。照片窗口可服务构图，但不得遮掉当前内容的必要信息；装饰选择角标不能冒充已完成的交互。
5. **交接**：输出可编辑网格/矢量或排版源、实际导出、规则说明、字体与来源状态。需要界面交接时按[开发视觉交接流程](../../../references/flow-handoff.md)映射到已有参数合同，不能把宣传图直接当成完整 UI 规范。

## 验收

按本轮约定产物选择检查项；只做符号研究时不额外要求宣传物料或整套字体样张。

- 制作符号时，隐去品牌名与颜色，核对轮廓是否表达了自身构思，并与两份参考保有身份差异。
- 交付小图标时，在目标尺寸检查阶梯边缘、孤立块、缝隙与视觉重量；缩放后出现细灰边或粘连时，修正导出或记录光学校正版。
- 制作系列时，将图标排在同一画幅检查家族性；主标志保持稳定，系列成员不能依赖颜色才能区分。
- 包含文字时，检查实际用到的标题、正文与语言；有中文才做中文试排。离散图形不强迫阅读文字降低清晰度。
- 制作应用时，逐件核对文案、图片窗口与真实状态；辅助图形不能被误读为图表数据、加载进度或功能选择状态。

## 验证范围

状态为 **provisional**。本轮核对一手来源，逐张查看全部原采集图或其等尺寸格式预览，记录 MIME、尺寸与 SHA-256。已生成并逐图目检原创静态概念；通用 Prompt 模板、正式品牌迁移、字体文件、真实界面、响应式和印刷测试仍未执行。清晰参考与静态概念目检不证明新品牌可自动复现。

素材属于第三方研究档案，公开获取不等于获得再分发权。PNG 预览是确定性格式转换，未做 AI 清晰化；正式新品牌资产须从自有可编辑源产生。

本包 2 张 AI 重新演绎与 8 张原创研究均已生成并逐图目检；图像入口见 [EXAMPLES](EXAMPLES.md)，具体范围与偏差分别见 [generated.json](generated.json) 和 [originals.json](originals.json)。原创研究验证的是文字简报下的静态概念、主体关系与画面表现；它们不证明正式品牌迁移、精确几何、真实字体、小尺寸或应用集成通过，因此保持 `provisional`。

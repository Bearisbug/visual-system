## 1. 从产品动作探索自己的离散符号

```text
任务：为 {{品牌名}} 研究一个由离散图形构成的品牌识别方向。
产品与受众：{{实际用途、使用者、品牌语气}}。
核心动作：{{用一个动作和对象关系表达价值，例如将分散事件连成可追踪路径}}。
应用条件：{{图标目标尺寸、传播比例、语言、背景与输出范围}}。
已有权威资产：{{已选字标/Logo/颜色/字体及版本；没有则写尚未确定}}。
精确文字：{{品牌名、标题、必要说明；若本轮只做符号则声明文字不在范围内}}。

参考：{{PG01 或 PG02 的具体图片文件}} 只控制 {{离散单位/阶梯正负形/符号与平滑文字的分工}}。
借用方法：用有限的 {{方块/直角条带/离散开口}} 表达核心动作，先做单色结构，再处理配色。
形状关系：{{独立单元、连接、间隔、方向与允许变化}}。
必须保持：{{已有品牌选择、明确主体与名称拼写}}。
允许探索：{{本轮尚未确定的轮廓、密度、开口或构图变量}}。

输出 {{本任务需要的方向数与文件形式}}，各方向使用同色同尺度比较，并给出核心动作如何落在形状关系上的说明。
不要使用参考品牌的猫/M 字、M/V 方形符号、原色阶、具体开口分布或字标造型。不能仅换色、改品牌名就称为新构思；不要为“科技感”添加无功能的随机像素。
检查目标小尺寸中的孤立块、开口、粘连和轮廓。正式名称以可编辑文字排版；字体家族、文件与许可无法确认时明确未知。
```

## 2. 把已选语言扩成图标与传播系列

```text
任务：将 {{自有品牌系统及版本}} 扩展到 {{产品系列或内容系列}}。
输入文件：{{自有可编辑主标志、字标、网格规则、字体/色彩参数、照片或内容素材}}。
成员与语义：{{每一成员的名称、功能/主题、精确文案}}。
尺寸与渠道：{{各图标实际像素、各物料比例、主要语言与最长标题}}。
参考 A：{{PG01 模型图标文件或 PG02 应用文件}}，仅说明 {{共同画法与不同主体/摄影窗口与辅助条带的分工}}。

固定项：{{标准 Logo、品牌名、网格单位关系、笔画/边缘、视觉重量、已选字体和颜色角色}}。
可变项：{{成员主体、内容窗口、条带长度、位置或辅助色}}。
分别维护标准识别、系列成员和装饰图形，不用成员变化反向修改标准 Logo。
先在统一画幅检查每个成员的轮廓与重量，再制作请求的真实应用。颜色以外也应能区分成员。
照片窗口需要保留 {{本内容必须可见的信息}}；装饰格线、选择角标或进度外观不能冒充真实功能状态。
文字使用实际内容，长标题需重新排版，不能删词来保留留白。

交付 {{可编辑源、导出格式、规则说明与保持项对照}}。
按实际目标尺寸查看开口和边缘；需要光学校正版时记录来源、用途和差异。界面交接只映射已经验证的资产与视觉参数，沿用项目现有 token 合同。
输出实际检查结果和未验证范围。静态物料不证明动效、响应式、字体覆盖或产品接入已经完成。
```

## 3. 修正离散资产的边缘或尺寸表现

```text
任务：修正 {{自有资产及版本}} 在 {{具体尺寸、背景、设备或印刷条件}} 下的 {{粘连/缝隙消失/非整数边缘/视觉重量问题}}。
权威输入：{{可编辑网格或矢量源、当前导出、实际问题截图}}。
保持：{{构思、部件数量、顺序、主轮廓、文字与已选色值}}。
允许调整：{{导出对齐、栅格化参数；或用户已授权的小尺寸光学校正}}。

先区分问题来自源几何、导出尺寸还是展示缩放。原件保持可追溯，修正另存版本。
若只是导出或展示问题，重新生成正确尺寸；不要用图像模型补绘几何。若需改变开口或笔画，在可编辑源中做有记录的光学校正，不能声称与标准母版逐像素相同。
输出修正文件与原文件的同尺寸对照，检查保持项和问题区域。没有取得可编辑源时说明缺口，只交当前能够验证的结果。
```

原创研究的具体简报、品牌、尺寸与数量见 [originals.json](originals.json)，仅属于对应研究，不是所有品牌的默认要求。源案例的身份与使用边界见 [REFERENCES](REFERENCES.md)；参考图不授予新品牌复制权。

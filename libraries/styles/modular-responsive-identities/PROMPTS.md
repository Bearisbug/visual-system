## 自有品牌的组合语法探索

```text
任务：为 {{品牌名}} 研究可组合的品牌视觉语言。
品牌与对象：{{产品价值、受众、需要共用识别的产品或内容系列}}。
应用与尺度：{{实际渠道、横竖比例、小尺寸用途、目标语言}}。
精确文案：{{品牌名、各内容标题、必要元数据及最长文案}}。
权威资产：{{自有已选 Logo、字标、配色、字体与版本；尚未确定的部分明确列出}}。

参考 A：{{MR01 或 MR02 的具体文件}}，只控制 {{内容容器/基本形展开/固定与变化的关系}}。
参考 B：{{可选的自有资产或另一参考；不用则删除此行}}，仅控制 {{独立职责}}。
构思：从本品牌的 {{产品动作、对象关系、名称含义}} 提出自己的单元语法。
固定项：{{核心符号、名称拼写、已选图文比例与配色约束}}。
可变项：{{单元数量、容器宽窄、聚散、排列方向、材料或内容长度}}。
明确区分：标准 Logo、辅助图形和内容容器，辅助变体不能冒充 Logo 母版。

输出 {{本任务所需的方向或变体}}，用同一套真实内容展示小识别、长短标题及 {{请求的传播比例}}。给出固定项/可变项对照，解释每种变化为何仍属于同一品牌。
先检查平面单色的结构，再按 {{品牌语气}} 决定是否加入颜色或材料。不要使用参考品牌的三形符号、四向标志、特定切口字形或原配色组合；新构思差异不能只靠换字换色。
检查：名称和文案完整、核心识别稳定、辅助图形不遮挡内容；超出已声明变化范围的结果单列，不能称为系统内变体。
```

## 已选系统扩展与参数交接

```text
任务：将 {{已选自有品牌系统及版本}} 扩展到 {{具体产品、内容或渠道}}。
输入：{{可编辑母版、标准组合、单元规则、既有品牌参数、真实文案}}。
参考：{{具体图文件}} 只说明 {{内容适配或组合层级}}，不授权重绘输入 Logo。
必须保持：{{品牌名、母版结构、部件顺序、既有产品关系及用户已确认选择}}。
允许变化：{{明确的容器、间距、尺度、排列或辅助表现变量}}。
目标条件：{{语言、最长标题、横竖比例、小尺寸、模式}}。

先列输入规则是否足以覆盖新场景，再制作对应的平面样张和参数表。遇到规则不能覆盖的场景，提出该场景的局部扩展并标明影响；不得静默扩大所有变体的权限。
比较各样张中的标准识别、辅助图形和内容容器，检查小尺寸开口、颜色之外的产品区分方式、文案完整性和可读性。发现需要光学校正时把它作为有用途和来源的独立版本记录。
交付 {{所需的可编辑物料/视觉参数说明}}。若交接到界面，只映射已通过目标场景验证的形状、间距、字体、色彩角色与资产；使用项目当前 token 合同，不实现业务页面，不把宣传图形直接定义成按钮或状态图标。
输出保持项比对、实际验证结果与未验证范围；图片展示不能证明动效、暗色和响应式行为已经可用。
```

没有权威母版时，输出状态只能是探索。正式色版、标志组合和小尺寸资产从自有可编辑母版导出；对 Prompt 中的“保持”要求逐项检查，措辞本身不构成通过证据。

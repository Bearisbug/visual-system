## 新构思探索

```text
Design an original {{symbol or lettermark}} for {{brand and product meaning}} using {{ribbon, outlined route, folded band or interlocking path}}.
Start with a clear path plan: {{turns, endpoints, openings and crossing order}}. The relationship should communicate {{one concrete idea}}.
Use the reference for {{path logic only}}. Create a different silhouette and internal structure. Keep {{chosen construction}} coherent. Add {{optional limited gradient}} only to explain overlapping surfaces.
Compare color and single-color structure at {{actual size}}. Avoid treating every technology brand as an infinity-loop problem.

```

## 已选版本定向修改

仅在已有自有品牌选定稿且用户要求局部调整时使用：

```text
Use {{approved own-brand artwork}} as the authority for {{silhouette, parts, letter sequence and composition}}.
Change only {{requested variable}} to achieve {{observable improvement}}.
Keep {{accepted decisions}} unchanged.
Use {{style reference}} only for {{specific permitted shape, spacing or expression property}}.
Show the result beside the approved version at {{comparison size}}.
If the request changes the concept, create a clearly separate concept instead of labeling it a minor revision.
```

## 输出核对

- 沿路径能读懂转向与交叠顺序；意外粘连或断裂需修正。
- 单色和小尺寸下主体关系仍成立；必要时把渐变层次改成明确的开口或分区。
- 不将作者网格中的黄金比例说明变成通用数值要求，具体尺寸需实际验证。
- 换品牌时重新设计路径、端点与内部留白；改渐变不算新构思。
- 对照输入图与实际结果，确认“保持”要求真的生效。
- 图中文字仅为探索参考；正式名称、字体与几何在可编辑母版中核对。
- 本模板没有工具专用参数；使用时按当前可用工具的真实接口提交。

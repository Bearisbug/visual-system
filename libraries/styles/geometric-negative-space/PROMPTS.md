# 几何负空间 · Prompt

当前库内例图的完整实际 Prompt、输入和输出以 [generated.json](generated.json) 为准，图像见 [EXAMPLES](EXAMPLES.md)。以下是供新任务使用的模板；按[艺术方向](../ART-DIRECTION.md)选择克制表现，用户已定品牌优先。模板的迁移状态与样例重绘分别记录。

按 [STYLE.md](STYLE.md) 判断适用范围。以下为研究者依据样本编写的自然语言模板，未实测，不是原作者提示词。提交前替换全部字段，用户已确定的选择与当前任务范围优先。

## 新构思探索

```text
Create an original flat geometric mark for {{brand}} and {{purpose}}. Express {{primary idea}} using {{solid shape family}} and a deliberately designed {{counter or opening}}. Let the solid silhouette and the empty area both remain readable. Use {{symmetry and edge character}}, {{brand palette}}, and {{wordmark relationship}}. Preserve generous, legible gaps at {{target size}}. Borrow only the construction principle from the references; invent the actual silhouette, spacing and semantic combination for this brand. Present {{canvas and background}}. Exact lettering: {{text or none}}.
```

## 已选版本定向修改

仅在用户要求局部修改且已有自有品牌选定稿时使用：

```text
Use {{approved own-brand artwork}} as the geometry and lettering reference.
Preserve {{approved silhouette, letter sequence, composition and palette}}.
Change only {{requested variable}} to achieve {{observable correction}}.
Use {{style reference}} only for {{permitted line, rhythm or hierarchy property}}.
Show the revised artwork beside the approved version at {{comparison size}}.
Do not replace the established concept unless the user requested a new concept.
```

## 结果核对

- 分别检查实形和空白的边界是否清楚；选择双重含义时，再分别核对两层识别。
- 缩小、反白后检查缺口粘连与箭头/字母误读。
- 比较与参考的外轮廓、切口位置和构图，排除仅换色换名字。
- 实际对照输入与输出；提示词中的“保持”不代表已经保持。
- 生成文字与几何仅作为探索，正式资产另经可编辑母版制作及对应用途验证。

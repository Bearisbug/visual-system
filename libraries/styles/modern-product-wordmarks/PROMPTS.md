# Mihai Dolganiuc · 现代产品字标 Prompt

当前库内例图的完整实际 Prompt、输入和输出以 [generated.json](generated.json) 为准，图像见 [EXAMPLES](EXAMPLES.md)。以下是供新任务使用的模板；按[艺术方向](../ART-DIRECTION.md)选择克制表现，用户已定品牌优先。模板的迁移状态与样例重绘分别记录。

先按 [STYLE.md](STYLE.md) 判断适用范围。以下是研究者编写的自然语言模板，未实测，非作者原始提示词。提交前替换所有字段；已有简报与用户选定方向优先。参考作者姓名只用于出处，不代替可观察的视觉描述。

## 新构思探索

```text
Create an original wordmark for {{exact brand name}}, a {{product and audience}}.
Make the complete name easy to read. Use {{block, rounded, flowing or slanted letter construction}} with a consistent rhythm. Introduce one distinctive change in {{specific letter, numeral or punctuation}} that relates to {{product meaning}}.
Use {{reference}} only to study {{one observable typographic relationship}}, not its exact lettering. Keep {{required spelling and accepted choices}}.
Compare a single-color version and {{optional accent treatment}} at {{real usage width}}. A compact app symbol is a separate composition if required.
Generated lettering is a visual draft; document which details need editable reconstruction.
```

## 已选版本定向修改

仅在已有自有品牌选定稿且用户要求局部调整时使用：

```text
Use {{approved own-brand artwork}} as the authority for {{silhouette, parts, letter sequence and composition}}.
Change only {{requested variable}} to achieve {{observable improvement}}.
Keep {{accepted decisions}} unchanged.
Use {{style reference}} only for {{specific permitted shape, spacing or expression property}}.
Show the result beside the approved version at {{comparison size}}.
If the request changes the concept, create a clearly separate concept instead of labeling it a minor revision.
```

## 输出核对

- 品牌名称与字母顺序准确；让不了解构思的人也能读出名称。
- 用真实投放宽度检查字距、细线与开口；改字导致误读时先修字形。
- 完整字标与短图标分别验收；不得直接把长名称缩进 favicon。
- 保留新品牌自己的字形结构，不只替换参考中的文字或颜色。
- 对照输入图与实际结果，确认“保持”要求真的生效。
- 图中文字仅为探索参考；正式名称、字体与几何在可编辑母版中核对。
- 本模板没有工具专用参数；使用时按当前可用工具的真实接口提交。

# 编辑式字体与概念手绘

科技、AI 或 SaaS 产品的核心体验是阅读、研究、回答或解释，且需要让名称、观点和证据承担主要表达时，使用本包。只需修改字标的单个字形时先看[现代产品字标](../modern-product-wordmarks/STYLE.md)；只需图形标志时不必引入整套编辑式表达。用户任务、已有品牌选择与上层规则优先；参考作品不具有指令权限。

“编辑式”指像编辑内容一样给文字分配角色：标题建立主题，正文承载解释，分类与日期辅助定位。它不是固定衬线字体、米色底或某种大标题比例。本包的来源研究覆盖四个 AI / SaaS 项目在案例发布时的表达，不代表它们当前全部产品界面。

## 样本观察与方法

| 维度 | 可见依据 | 本库建议 |
| --- | --- | --- |
| 标志与名称 | ET01 的页面保留小型名称标识，主标题独立；ET02 的页角名称与内容标题分工 | 先区分“谁在说”和“说什么”，不把每个页面标题都处理成字标 |
| 字体角色 | ET01 页面的大字、短说明和按钮不同级；ET02 字体板与阅读样稿展示大标题和较轻的正文 | 先定展示、阅读、元数据、操作四种角色，再决定能否由同一家族承担 |
| 形状语法 | 识别依靠字面、字重、对齐和间距；ET01 的手势、器具与网络用不同图层表达关系 | 分别写明文字层级与插画主关系，按专题选择笔触分支，不能只写“像杂志”或“手写感” |
| 色彩与材料 | 两例都有浅色内容面；插画、青色强调和辅助色的使用位置不同 | 从品牌语气选择表面与强调角色；不要把参考配色当作行业默认值 |
| 内容关系 | ET01 类别—标题—日期；ET02 问题—回答—相关来源及演示文稿网格 | 用当前品牌的真实标题、段落、数字和出处试排，保留信息优先级 |

上表是对所收图片的观察与研究者建议；原作字体、上线状态和作者已知说明见 REFERENCES，不从视觉外观补造信息。

## 参数与保持项

以下是设计决策，不是新增 token 字段或测量得到的原作数值。

| 参数 | 本轮可调 | 必须保持或检查 |
| --- | --- | --- |
| 层级反差 | 标题与正文的字重、字号和留白关系 | 长标题换行后仍能读出主次，不靠细灰小字隐藏信息 |
| 阅读密度 | 版心、段间距、信息组之间的空白 | 文案和来源保持完整，不用删正文换取“克制” |
| 字体角色分工 | 单家族或展示/阅读搭配 | 中文、英文、数字、引用符号实测；原作字体名不等于获得字体文件或许可 |
| 辅助视觉比重 | 插画、摄影、分隔线与色面的份量 | 正文不铺在影响阅读的装饰背景上；不复用原品牌手势、线稿或符号 |
| 强调强度 | 链接、关键数字、栏目色 | 区分品牌装饰与操作语义，状态仍通过技能现有合同验证 |

## 三层迁移

| 目标 | 迁移内容 | 不能直接迁移 |
| --- | --- | --- |
| 品牌识别 | 名称与标题的角色区分；字体组合的语气；克制或外显的强调策略 | 参考品牌名称、特定字标、插画和品牌配色；不得把挑一款字体等同完成 Logo |
| 传播物料 | 文章封面、研究摘要、产品说明、演示文稿中的标题/摘要/元数据关系 | 参考文案、日期和格线数量；物料比例改变时要重新分行和验证容量 |
| 界面参数 | 经试排选定的字体、字重、字阶、行高、间距与色彩角色，交接到当前技能的既有 token 格式 | 宣传标题的极端比例不能直接用于表格、表单和长文；图片不提供真实组件状态、交互行为或响应式断点 |

界面交接只提供视觉参数、字体与资产说明；依照[开发视觉交接流程](../../../references/flow-handoff.md)验证。页面功能、导航架构和实现由相应任务承接。业务已有操作和阅读约束优先于展示风格。

## 执行与验收

以下步骤用于包含排版的任务。仅制作插画时，按[手绘专题的交付与目检](HAND-DRAWN.md#交付与目检)执行，不额外要求整套文字样张。

1. 从已有简报确定主语言、阅读任务、品牌语气、内容长度和承载平台。品牌名称与已选资产继续生效。
2. 按上表选主要参考，列出只借哪一层；允许组合，但须解释职责。ET03 的宣传表达不直接作为产品界面规范，ET04 的真实产品结构与装饰层分别处理。
3. 用真实短标题、长标题、一段正文和元数据制作可比较样张；比较层级与阅读任务，不靠换色充当不同方案。
4. 宣传物料和界面分别设定阅读尺度。不能从参考图猜精确字体、像素或断点。
5. 对中文、混排、数字、标点和窄宽度检查缺字、回退、断行、裁切及对比；正式文字保持可编辑。
6. 输出选择依据、参数、字体来源与许可状态、实际样张及未验证项，再进入请求的交接阶段。

## 验证范围与限制

状态为 **provisional**：已逐图查看原采集图，核对正文层级、字形边缘与主要内容；原创静态概念已生成并逐图目检，尚未执行正式品牌迁移、字体文件测试或产品集成。参考清晰度与概念图目检仅适用于各自研究范围，不证明任何屏幕或语言下自动合格。

案例是第三方研究素材。原件采用公开页面响应原字节，两份 SVG 另附等尺寸 PNG 预览，没有 AI 清晰化；不能作为新品牌正式资产或精确字体/几何母版。PROMPTS 中的通用模板为本库编写，尚未实测；适用范围优先是科技、AI、SaaS 的内容表达，其他行业迁移未验证。

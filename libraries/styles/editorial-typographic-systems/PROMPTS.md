# 编辑式字体与信息层级 · Prompt

库内 AI 重新演绎的实际 Prompt、输入和输出见 [generated.json](generated.json)；从文字简报生成的原创研究见 [originals.json](originals.json)，图像统一展示于 [EXAMPLES](EXAMPLES.md)。两类生成记录各自保存逐图目检；原创研究不对应源案例，其主体与生成细节不归属于原作者或原品牌。以下通用模板尚未实测，不能用上述实际生成记录代替模板验证。按[艺术方向](../ART-DIRECTION.md)选择表现，用户已定品牌优先。

先读 [STYLE.md](STYLE.md) 的适用条件与[案例](EXAMPLES.md)。下列是本库编写、尚未实测的工具无关完整模板；参考图仅控制明确列出的视觉关系。提交前替换全部占位字段，不使用作者名代替视觉描述。工具参数、文件引用和编辑能力按当前实际接口设置。

需要直接了解如何填完整任务时，读 [拾序：概念传播](CASE-STUDIES.md#brief-shixu)或[应答台：产品说明](CASE-STUDIES.md#brief-replydesk)。两个名称和任务均为本库虚构的迁移演示；给出了精确文案、参考职责、图像与排版分工、两类应用、交付与验收，但没有生成效果证据。

## 品牌表达探索

```text
任务：为 {{品牌名}} 研究以文字和内容层级为主的视觉系统。
品牌输入：{{产品提供的价值、受众、希望形成的语气}}。
应用：{{实际物料或界面样张类型、画布或目标尺度}}。
语言与原文：{{语言；精确品牌名；短标题；长标题；正文；日期或来源等元数据}}。
已有选择：{{已确定的 Logo、配色、字体、资产及版本；没有则明确写无已有选择}}。

参考 A：{{ET01–ET04 的具体文件}}，只参考 {{文字角色、信息分组、留白或对齐关系}}。
参考 B：{{可选的自有品牌资产或另一例文件；不用则删除此行}}，仅控制 {{与参考 A 不冲突的职责}}。
构思：用 {{本品牌的内容特征或阅读行为}} 建立识别，明确区分品牌名称、主题标题、阅读正文、元数据和操作文字。
字体策略：{{单家族或展示/阅读搭配；可用字体与未知项}}。
允许变化：{{层级反差、版心密度、强调强度、辅助图形比重}}。
必须保持：{{精确文案、既有母版、用户已定的品牌语气与用途}}。

输出：提供 {{所需的比较方向或单一方向}} 的平面研究样张和参数说明，覆盖上述真实内容。说明每一文字角色由什么变化区分，以及传播物料与界面分别如何处理阅读尺度。
限制：不用原品牌的名称、字标、插画或特定配色组合；不虚构原作字体或精确网格。不因排版困难删减正文或来源。图像中的文字只作研究，正式文字需在可编辑源中重新核对。
核对：检查长短标题、混排、数字、标点、内容完整性及可辨层级；把未知字体、未做的窄宽度和对比度验证单列。
```

## 已选方案调整与视觉交接

```text
任务：调整 {{本品牌已选方案及版本}} 的 {{明确问题}}，并提供 {{传播物料参数/界面视觉参数}}。
权威输入：{{自有 Logo 母版、已确认字体与品牌参数、真实文案}}。
目标场景：{{目标语言、平台、内容长度、浅暗模式及实际尺寸}}。
风格参考：{{具体文件}} 只用于 {{某个层级或阅读关系}}，不是资产来源。
保持项：{{名称拼写、母版几何、信息优先级、已定品牌选择}}。
本轮允许修改：{{一组与问题直接相关的字号/字重/行高/间距/色彩角色}}。

先把问题映射到文字角色，再列出修改前后参数和预期可见改进。让同一份正文、最长标题及元数据在目标场景出现；不得靠替换成短文案掩盖容量问题。
输出可编辑样张、参数选择理由、字体来源和许可状态、视觉核对结果。界面参数使用项目当前既有 token 合同，未知字段记为待定，不创建另一套 schema；不要实现业务页面或改变功能结构。
检验：逐项比对保持项，检查内容完整、字体回退、断行、对比与目标尺度；失败时说明具体字段与场景，不能以“风格统一”替代实测。
```

## 手绘概念插画

先按 [HAND-DRAWN.md](HAND-DRAWN.md) 选具体图与笔触分支，再填写下面的模板。它们是交给 Agent 的完整任务说明；调用图像工具时只提交图像目标和约束，说明、命名和验收由 Agent 另行完成。工具的文件引用、透明背景、数量和尺寸能力以实际接口为准，不能把文字字段当作已生效参数。

### 单幅概念图

```text
为 {{自有品牌名}} 制作一幅手绘概念插画，用于 {{真实场景、承载尺寸和画面比例}}。
要表达的产品含义：{{一句可核对的功能或价值，不写未经证实的能力}}。
主体、动作和对象：{{谁／什么，对什么，做什么；具体可画的关系}}。
自有品牌输入：{{已定颜色、资产及需沿用的语气；未知项明确写出}}。

参考 A：{{本包具体图文件}}，只参考 {{干涩轮廓与擦印填色／平滑变宽轮廓，二选一并说明细节}}。
参考 B：{{自有构图稿；没有则删此行}}，只控制 {{主体位置、动作或品牌资产}}。
画面内容：{{主体、直接关联部件、必要背景}}。
线条：长走势稳定，转折和收笔有自然变化；不要在全部轮廓叠加等距锯齿或随机抖动。
色彩分工：{{背景色角色}} 承托画面，{{墨线角色}} 表达主体，{{辅助填色角色}} 分离对象；{{强调形及真实强调目的；不需要时删去}}。
构图：{{视角、重心、主体占幅及需保留的孔隙}}。
正式文案：由后续可编辑排版加入，本次图中不生成品牌名、标题、假文字、标签或签名。
输出背景：{{平底或透明；透明时同时使用工具支持的透明设置}}。

保持所选笔触分支、真实动作和图层可辨性。重新设计主体和关系，不复制参考里的手势、侧脸、牛顿摆或节点组合。手不是必需部件；有手时让接触点、抓握方向和连接成立。不加装饰性 3D 光效、界面截图或与概念无关的密集图案。
交付图像，并在图外简述构思、参考职责和实际输出尺寸。逐项检查主体与动作、交点、图层对比、纹理和目标尺寸；如要求透明，检查实际 Alpha。没完成的检查如实记录。
```

### 同一产品的插画系列

```text
为 {{品牌名}} 的 {{应用}} 制作 {{实际数量}} 幅可并列使用的手绘插画，尺寸为 {{承载尺寸与比例}}。
主题清单：{{每幅分别列出主题、对象、主动作和要表达的关系}}。
已选方向：{{自有已确认图及版本；尚未确认时写出共同画法，不冒称已有通过样张}}。
风格参考：{{具体参考图文件}}，仅控制 {{线条、填色与背景职责}}。
共同保持：{{一个笔触分支、墨线与辅助色角色、背景处理、物体比例、视角、细节密度}}。
逐幅允许变化：{{对象、动作、构图、为概念所需的强调形}}。
正式文字由独立排版源维护，插画中不生成文字或品牌标识。

先检查每个主题是否有具体可画的主关系；几个主题若只有名称不同，先重写构思。沿用共同画法，分别使用与主题相关的物件，不将同一只手、拼图或线团换底色作为整个系列。
若当前工具不能一次保持整个系列，按图逐次制作，并使用已确认的自有图作画法参考；不能宣称 Prompt 已保证一致性。
交付各幅独立图像及并排检查结果。核对每幅概念、线条和图层；再比较整个系列的比例、笔触、背景与颜色职责。记录真实文件、实际工具、保持项偏差和修正结果。
```

### 文章封面与文字区域

```text
为 {{品牌名}} 的文章 {{真实标题}} 制作封面插画及可编辑排版样稿。
画布与最终显示场景：{{比例、尺寸、卡片或文章页中的承载尺寸}}。
精确文案：标题 {{标题}}；说明 {{说明}}；元信息 {{类别、日期等已知信息}}。
插画概念：{{具体物件、动作、关系}}。
参考图 {{具体文件}} 只控制 {{笔触分支与图层分工}}；品牌输入为 {{自有 Logo、颜色、字体来源及许可状态}}。
布局选择：{{独立插画与文字分栏／图形退到边缘／上下分区，并给出文字安全区的位置与范围}}。

图像工具只制作插画和背景；明确保留上述文字安全区，不生成文字、标志、按钮或假界面。安全区内不用密集颗粒、穿越线稿或强调形。保持 {{本品牌已确认的画法和颜色职责}}。
在可编辑排版源中加入完整标题与元信息，分别设定展示、阅读和元数据角色。若有中文，核对真实文案、引号、数字和缺字；字体文件或许可未取得时记录缺口，不以源品牌商用字体名作为可交付文件。
交付独立插画、可编辑排版源及预览。检查文字避让、最长文案、目标卡片尺寸与缩略阅读；比例改变时重排，不能只缩小整张带字图片。报告实际检查结果与未测项。
```

### 已选插画局部修正

```text
编辑自有插画 {{输入文件、版本}}，用途和尺寸为 {{场景与尺寸}}。
本轮问题：{{具体到手部接触、轮廓粘连、过密细节、纹理或文字区侵入的一项或一组问题}}。
保持项：{{主体、主动作、构图、配色、笔触分支及用户已确认部分}}。
允许修改：{{与问题对应的局部形状、位置、粗细、纹理或密度}}。
参考 A 是待修改自有图，决定保持项；参考 B {{具体风格图文件；不需要则删此项}} 只说明 {{局部画法职责}}。

先实际查看输入，再只修上述问题。不以整体换色、换纸纹或换题材代替指定修正。使用工具真实支持的图像编辑与引用机制；需要透明输出时保持或设置透明，并实际检查 Alpha。
交付修改后图像及输入／输出对应关系。并排核对主体、动作、比例、颜色和文字安全区；不得仅因提示词写了“保持相同”就宣称几何完全相同。像素级一致若未测，明确说未测。记录偏差与仍待修正之处。
```

模板本身没有执行记录，不把参考图或填写后的提示词当作生成迁移通过证据。新任务实际输出与评审通过后，另记任务、输入、版本和范围。

# 选择简约的品牌方法

从实际表达需求选择，执行依据见 [BD-REF-001](../../references/design.md#bd-ref-001)。默认研究[当前艺术方向](ART-DIRECTION.md)，用户已有品牌与明确要求优先。没有匹配包时可以提出新的方法，不强套标签。

| 本轮要解决的问题 | 优先比较 | 看什么 |
| --- | --- | --- |
| 知识、写作或研究产品，希望安静且有人味 | [编辑式](editorial-typographic-systems/STYLE.md)、[现代字标](modern-product-wordmarks/STYLE.md) | 文字层级、字形节奏与概念插画怎样分工 |
| “Anthropic 那种手写风”、暖底黑线的 AI 概念图 | [手绘专题](editorial-typographic-systems/HAND-DRAWN.md) | 物件与动作、自然笔触、图层明度；正式文字独立处理 |
| 产品名称就是最重要的识别 | [现代字标](modern-product-wordmarks/STYLE.md) | 整词阅读与一处有意义的改字；自然笔势可作为分支 |
| 缩写、开发工具或基础设施需要紧凑图标 | [几何字母](geometric-letter-monograms/STYLE.md)、[负空间](geometric-negative-space/STYLE.md) | 字母骨架、共笔、开口与小尺寸可辨性 |
| 产品功能能转成清楚的动作或关系 | [科技语义](semantic-tech-marks/STYLE.md)、[黑白产品](monochrome-product-marks/STYLE.md) | 构思是否来自真实含义，去掉材质后能否成立 |
| 企业与长期平台需要稳定形象 | [现代主义](modernist-corporate-symbols/STYLE.md) | 强轮廓、稳定组合、单色识别和应用尺度 |
| 希望有手工线条的艺术性，主体仍清楚 | [单线轮廓](monoline-contour-marks/STYLE.md)、[编辑式](editorial-typographic-systems/STYLE.md) | 是识别符号还是叙事插画；不用细节堆出气氛 |
| 多产品、模型家族或协作平台需要变化 | [模块化](modular-responsive-identities/STYLE.md)、[像素网格](pixel-grid-identities/STYLE.md) | 固定部件、变化的含义、平滑文字与图形的关系 |
| 连接、流转或折返是产品的核心关系 | [折带路径](folded-ribbon-paths/STYLE.md) | 平面穿插是否已足够，不靠渐变掩盖不清楚的路径 |
| 科学、仿真或机器学习的主视觉需要雕塑感 | [参数化](parametric-science-visuals/STYLE.md) | 单个主形、连续边界、留白与真实数据的区别 |
| 独立 App 需要克制的产品图形 | [黑白产品](monochrome-product-marks/STYLE.md) | 功能隐喻、字形、抽象构成与浅体积分别选择 |

在[案例导航](CASEBOOK.md)看不同方法的实际 AI 示例；要判断来源作者、字体或原品牌事实，读取包内 `REFERENCES.md`。不能从重绘图反推官方规范。

选择记录写清“哪个样例的哪个变量用于什么”，例如“ET01 的概念动作与墨线关系”或“N01 的正负形张力”。同一变量由一个明确依据决定，避免同时叠加两套完整品牌语言。

只研究方向时交付选择依据、图像角色与下一步验证；不强制先做 Logo、tokens 或界面。对新品牌采用方法时重新建立自己的主体关系，不能直接换名、换色交付库中标志。

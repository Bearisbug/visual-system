## 新构思探索

```text
Create an original modernist corporate symbol for {{organization}} that expresses {{one brand-specific idea}} through {{abstract or pictorial construction}}. Build a compact, memorable outer shape with {{geometry and negative-space priorities}}. Use {{color strategy}}, but make the structural idea work in a one-color study first. The references demonstrate clarity, reduction and symbol-to-name hierarchy; do not recreate their recognizable outlines, divisions or color arrangements. Show an isolated symbol and a restrained lockup with the exact name {{name}} for {{application and target size}}. Keep the concept distinct from the reference brands.
```

## 已选版本定向修改

仅在已有自有品牌选定稿且用户要求局部调整时使用：

```text
Use {{approved own-brand artwork}} as the authority for {{silhouette, parts, letter sequence and composition}}.
Change only {{requested variable}} to achieve {{observable improvement}}.
Keep {{accepted decisions}} unchanged.
Use {{style reference}} only for {{specific permitted shape, spacing or expression property}}.
Show the result beside the approved version at {{comparison size}}.
If the request changes the concept, create a clearly separate concept instead of labeling it a minor revision.
```

## 输出核对

- 图形与名称拆开后，图形仍有独立结构和可描述特征。
- 实际检查单色、反白与目标尺寸；不能从来源品牌声誉推定新图自动通过。
- 对照参考轮廓与新设计，区别存在于构思和结构，而不只是名称与颜色。
- 对照输入图与实际结果，确认“保持”要求真的生效。
- 图中文字仅为探索参考；正式名称、字体与几何在可编辑母版中核对。
- 本模板没有工具专用参数；使用时按当前可用工具的真实接口提交。

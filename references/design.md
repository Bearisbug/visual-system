# 构思与迭代

<a id="bd-input-001"></a>
## BD-INPUT-001 · 范围与既有选择

- 触发：新品牌任务、接续已有稿，或只执行一个阶段。
- 规则：先从上下文和现有文件提取名称、业务、受众、用途、已选稿与约束；事实、建议和待定项分开。用户已确认的信息和授权持续有效，只问会改变结果的缺项。用户授权自主决策时记录理由并继续；不得替换其品牌或擅自扩大到产品功能设计。
- 产物：简短 brief 与本次交付范围，保存到用户项目指定位置。没有指定时选择项目内稳定品牌目录并说明；测试品牌留在测试目录。
- 验证：输入能追溯；当前阶段和最终文件有对应关系；进入后续阶段不要求重做已有成果。

<a id="bd-ref-001"></a>
## BD-REF-001 · 参考角色

- 触发：比较视觉方向、给定作品、指定设计师、选择风格包或消费来源图片。
- 规则：先按本轮交付对象、产品含义、语言和使用尺度筛选[风格索引](../libraries/styles/INDEX.md)，可用[选择表](../libraries/styles/SELECT.md)定位；再按标志类型、构思、形状、材质、排版和应用角色读取命中包。将每张图标为相应参考角色；自有选定稿另标为几何依据。组合风格时写清各自负责的变量与冲突时采用的方向；无匹配包时从简报提出新方法，不强套标签。观察、推导和未知项分别陈述；禁止把少量样本推广成设计师全部方法，或把第三方符号直接作为新品牌交付。
- 产物：来源 URL/文件、实际查看范围、参考角色与可迁移关系。浏览库内例图先读 `EXAMPLES.md` 的身份标注：AI 重新演绎按 `generated.json` 展示，并通过 `source_sample_id` 连接原作；独立原创研究按 `originals.json` 的简报、方法与实际 Prompt 展示，不补造原作、设计师或真实品牌采用记录。研究原作或指定来源记录时按 `sources.json` 的 `display_file` → `detail_file` → 关联 `preview_file` 展示，原件继续用于溯源。分别标注 AI 重新演绎、AI 清晰化与原创研究；重绘改变的变量、辅助图形替代原主体的范围，以及实际传图与仅看过的参考均按记录说明。AI 图不能证明原作细节、字体、精确几何或官方配色；原图与其派生图不重复计案例，原创研究按独立构思计数。
- 验证：实际查看每个入选主体在使用尺寸下的清晰度；不能只查画布尺寸。来源不足时按风格索引的清晰度流程处理，能力受限时按 [BD-RUNTIME-001](runtime.md#bd-runtime-001)交付文字假设与待目检项，禁止插值放大冒充清晰化。`provisional` 及单张研究图通过均不等于真实品牌采用、商标清查或完整迁移效果已验证。

<a id="bd-concept-001"></a>
## BD-CONCEPT-001 · 概念差异

- 触发：首次探索、要求更多方向或明确要求换构思。
- 规则：将产品的一个关键动作、名称关系或意象变成形状逻辑；方向数依据任务与预算，不设全局配额。不同方向必须在意象、轮廓或内部构造上有实质差异；换色、换背景或渲染不算新构思。允许直接用可编辑向量探索，也可生图探索；方法和输出类型如实记录。
- 产物：每个方向的稳定 ID、图像、构思说明、采用的参考关系、实际 Prompt/构造方式及版本。推荐基于当前品牌用途、可辨性与独特结构，不按作者名气或某种固定“科技元素”决定。
- 验证：并排看实际图形；去掉颜色和材质后仍能说明方向区别。替换品牌后必须形成新轮廓或内部关系，不能只换参考名称。

<a id="bd-edit-001"></a>
## BD-EDIT-001 · 选择与改动

- 触发：用户给反馈、指代某张图、回选早期稿或要求局部修改。
- 规则：先唯一定位方向 ID、版本与真实图像，再分别判断造型、配色、材质、字标是否已定。将反馈归入换构思、修轮廓、换材质/配色或改应用；只修改被授权的变量。新要求与旧简报冲突时以较新的明确选择为准；“第二个”等指代无法唯一确定时，只询问这个指代，不猜成最终选择。
- 产物：selection 记录与新版本；记录本轮改变项、保持项、用户反馈或自主决策依据，保留可回看的输入版本。
- 验证：输入与输出并排核对保持项；错误部件、拼写或结构漂移必须修正，不能仅凭 Prompt 写了“保持”就判通过。

<a id="bd-material-001"></a>
## BD-MATERIAL-001 · 轮廓与表现

- 触发：已有自有标志，研究颜色、质感、立体或展示应用。
- 规则：把确定的轮廓设为几何依据，材质参考仅控制可见表面与光照。需要精确普通色版时从母版导出；生图结果视为展示研究，逐项检查孔洞、部件、比例和文字。材质输出不能冒充编辑源或基础小图标。
- 产物：材质/配色版本与输入母版对应关系；完整提示词、实际工具、参考角色、输出及复核。图像工具不可用时记录当前缺项，不用矢量渐变演示冒称该工具已实测。
- 验证：对照母版与目标使用尺寸，确认身份结构和负空间；背景/透明度以实际文件为准。需要光学校正版时走 BD-EXPORT-001 的明确例外记录。
